# Node hardware smoke test

Build and upload with the PlatformIO environment `smoke-node`.

The test passes when:

- the status LED on PB1 (physical pin 6) remains steadily on while the laser
  illuminates the LDR;
- interrupting the beam makes the LED blink at approximately 4 Hz;
- restoring the beam returns the LED to steady operation; and
- the LED does not rapidly alternate near the switching point.

Blinking is generated by Timer1 hardware without timer interrupts. The initial
ADC thresholds are 240 for a broken beam and 224 for a clear beam; these are
development values rather than calibrated production settings.
